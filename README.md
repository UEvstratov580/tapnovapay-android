# TapNovaPay Android Wallet

Офіційний Android гаманець для криптовалюти TNP.

## Встановлення

1. Завантажте APK з Releases
2. Встановіть APK на ваш Android пристрій
3. Запустіть додаток

## Вимоги

- Android 5.0 (API 21) або новіше
- 50 MB вільного місця

## Розробка

### Збірка з вихідного коду

git clone https://github.com/UEvstratov580/tapnovapay-android.git
cd tapnovapay-android
qmake tapnovapay-android.pro -spec android-clang
make
